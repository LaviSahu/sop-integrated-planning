# S&OP Integrated Planning — Wiki Home

S&OP Integrated Planning is a pure-stdlib Python platform that runs a
synthetic appliance manufacturer's monthly planning cycle end to end:
demand plan → Rough-Cut Capacity Planning → constrained supply plan →
financial reconciliation → a self-contained HTML decision cockpit
comparing three scenarios side by side. This wiki is the
practitioner-facing reference layer — the README gets you running in
60 seconds, these pages explain *why* the engine is built the way it
is.

## Ground truth

Every number in this wiki and the README comes from actually running:

```bash
PYTHONPATH=src python3 -m sop_integrated_planning demo
```

against the synthetic "Cascade Appliances" dataset generated by
`datagen.py` (seed `20260714`). There is no real company called Cascade
Appliances — the product families, resources, prices, and demand curves
are invented for this repo. Nothing here is hardcoded downstream of
`datagen.py`: edit the seed or any constant table and every number in
the console output and the dashboard changes accordingly, and these
docs would need a re-run to stay accurate.
